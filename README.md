## Enterprise Financial Document Extraction and Processing using AWS aand RAG
This repository includes an architecture performing the extraction of structred document information from business enterprise data and RAG enabled analysis through Python and AWS.

### Architecture
The arcitecture details the stages of the document ingestion, information extraction, data storage, document processing, analysis, and results storage.
![Architecture](images/Extraction%20Project%20Architecture.png)

### Technology Stack

- Language: Python
- API: FastAPI
- Cloud: AWS
- Storage: Amazon S3 and DynamoDB
- AI: Amazon Textract and Amazon Bedrock
- Testing: Pytest
- Infrastructure as Code: AWS CDK
- CI/CD: GitHub Actions
